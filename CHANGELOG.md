# Что менялось

Версии идут по порядку, новые сверху. Номер версии стоит в заголовке коммита.
Подробности по каждой возможности смотрите в документации (docs).

## 0.18.0 (18 ноября 2026)

- Токены устройств с proof-of-possession: долгоживущая привязка Android-клиента.
- Android-приложение выпускает ключевую пару ECDSA P-256 в Keystore, публичный ключ передаётся на сервер при входе.
- 1 активное устройство на пользователя; отзыв из настроек безопасности или автоматически при смене пароля / logout.
- Новые эндпоинты:
  - `GET /api/auth/devices` — список устройств
  - `DELETE /api/auth/devices/:id` — отзыв
  - `POST /api/auth/security/revoke-all-devices` — отзыв всех (step-up с паролем)
- Guard сессий расширен: принимает и веб-куку, и Bearer-токен устройства с ECDSA-подписью запросов.

## 0.17.0 (15 ноября 2026)

- Обложка альбома по выбору пользователя.
- Общие альбомы отображаются в лентах.
- Верхняя панель значками.
