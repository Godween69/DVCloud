# DV Cloud

Домашнее облако для семейных фото и видео. Ставится на ваш сервер, хранит файлы на вашем диске
и никуда их не отправляет.

Я делаю его для своей семьи. Хотелось, чтобы снимки лежали у нас, а не у чужого сервиса, чтобы
их можно было листать по датам, находить по словам и показывать друг другу, и чтобы ничего не
пропадало из-за того, что программа сломалась. Получилось облако, которым я пользуюсь сам.
Оно работает, но проект живой: что-то я ещё доделываю, и об этом ниже написано честно.

Лицензия AGPL-3.0, исходный код открыт целиком. Ни счётчиков, ни внешних сервисов в нём нет.

## Что в нём есть

**Люди.** Регистрации нет: людей заводит администратор, каждому выдаётся логин и разовый пароль.
У каждого своё пространство и своя квота. Для детей есть отдельная роль с упрощённым
интерфейсом: смотреть своё и то, чем поделились, без загрузки и удаления. Второй фактор входа
подключается по желанию через [DV Auth](https://github.com/Godween69/DVAuth).

**Библиотека.** Лента по дате съёмки с полосой времени, миниатюры, просмотр оригиналов,
видео с кадром-постером. Фото с iPhone и Android (HEIC) тоже открываются. Вкладки «Фото»,
«Видео», «Скриншоты». Корзина, из которой можно вернуть файл. Загрузка идёт потоком и
докачивается после обрыва, можно перетащить целую папку. Дата снимка берётся из метаданных
файла, иначе из имени, и её можно поправить. В просмотре кнопка «Инфо» показывает, откуда
взята дата и что ещё известно о файле.

**Альбомы.** Обычные и общие: можно поделиться с другими людьми облака. Быстрый альбом,
в который фото кладётся одним нажатием. Облако само предлагает альбомы по событиям и поездкам,
а конструктор собирает альбом по условиям: период, откуда брать, кто должен быть на фото и
кого быть не должно. Альбом можно убрать в архив, скачать архивом ZIP.

**Люди на фото.** Облако находит лица, кошек и собак, собирает их в группы, и вы даёте имена.
После этого работает запрос «фото с Валей». Ваши ответы на «Проверить догадки» учат облако
узнавать людей точнее. Всё считается на вашем сервере, лица и биометрия никуда не уходят.

**Поиск по смыслу.** Запрос словами, в том числе по-русски: «собака на пляже», «закат»,
«скриншот переписки».

**Похожие.** Дубликаты и серии одинаковых снимков, чтобы освободить место. Ничего не удаляется
само: отмеченное уходит в корзину.

**Яндекс Диск.** Если у вас безлимит на Яндекс Диске, фото и видео можно перенести в облако
и сверять автоматически. Способ неофициальный, подробности и оговорки в docs/YANDEX.md.

**Админка.** Отдельная локальная страница, снаружи недоступная: люди и квоты, состояние
хранилища, файлы, дубликаты по всему облаку, исправление даты снимка, резервная копия по кнопке.

**Оригиналы лежат обычными файлами** в понятных папках. База данных хранит только указатели.
Если приложение сломается, фото останутся целы и откроются без него.

Чего здесь нет и не будет: публичных галерей, соцсети, внешних сервисов, рекламы, счётчиков.

## Чего пока нет

- Приложения для Android с автоматической выгрузкой с телефона. Оно запланировано, но я
  ещё не начал. Пока фото попадают в облако через сайт или с Яндекс Диска.
- Файлов общего назначения: облако только про фото и видео.
- Автоматического расписания резервных копий: копия делается по кнопке в админке.

## Как это устроено

    браузер  ->  ваш прокси с HTTPS  ->  сайт (React, Caddy)  ->  сервер (NestJS)  ->  Postgres
                                                                         |
                                                                  файлы на диске
    админка (только 127.0.0.1)  ->  сервер (внутренний порт, наружу не публикуется)

    необязательно, только для сервера, в интернет не выходят:
    служба ML (поиск по смыслу, лица, питомцы)
    помощник входа в Яндекс по QR

Подробно: docs/DESIGN.md (замысел и защита) и docs/STRUCTURE.md (устройство репозитория).

## Быстрый старт

Нужны Linux, Docker с плагином compose, Git и Node 22 (Node нужен один раз, чтобы записать пароль
админки). Это пробный запуск на своём компьютере. Выставлять облако в интернет можно только
за прокси с HTTPS, как описано в docs/DEPLOY.md.

    git clone https://github.com/Godween69/DVCloud.git
    cd DVCloud

    cp dvcloud.env.example dvcloud.env
    chmod 600 dvcloud.env
    sed -i "s/^DVCLOUD_INTERNAL_TOKEN=.*/DVCLOUD_INTERNAL_TOKEN=$(openssl rand -hex 32)/" dvcloud.env
    echo "POSTGRES_PASSWORD=$(openssl rand -hex 24)" > .env

    node apps/admin/bin/set-password.mjs dvcloud.env     # спросит пароль админки

    mkdir data && sudo chown 1000:1000 data
    cp docker-compose.example.yml docker-compose.yml
    docker compose up -d --build

Через минуту:

    curl http://127.0.0.1:8080/api/health

Админка открывается на http://127.0.0.1:3005. Войдите паролем, который задали, и создайте
человека: пароль для него покажется один раз. С этим логином заходите на сайт
http://127.0.0.1:8080 и грузите фото.

Дальше читайте docs/DEPLOY.md: там прокси с HTTPS, обновление, резервные копии и разбор типичных
неполадок. Поиск по смыслу, лица, Яндекс Диск и второй фактор включаются отдельно и по желанию.

## Документация

Начните с развёртывания, остальное читайте по мере интереса.

- docs/DEPLOY.md: как поднять облако у себя, прокси, обновление, первые шаги.
- docs/ADMIN.md: админка, роли, резервная копия, исправление даты.
- docs/BACKUP.md: резервная копия и восстановление.
- docs/WEB.md, docs/FILES.md, docs/PREVIEWS.md: сайт, хранение файлов, миниатюры и даты.
- docs/ALBUMS.md: альбомы, общий доступ, предложения, конструктор, архив.
- docs/PEOPLE.md: лица, питомцы, имена, «Проверить догадки».
- docs/SEARCH.md: поиск по смыслу и служба ML.
- docs/SIMILAR.md: дубликаты и серии.
- docs/YANDEX.md: перенос с Яндекс Диска.
- docs/AUTH.md и docs/TWOFACTOR.md: вход, пользователи, второй фактор.
- docs/DESIGN.md: замысел, принципы, защита.
- docs/STRUCTURE.md: структура репозитория, команды, миграции, лицензии зависимостей.
- docs/LICENSING.md: лицензия и чужие библиотеки.
- CHANGELOG.md: что менялось от версии к версии.
- CONTRIBUTING.md: как устроена работа над проектом и как предложить правку.

## Разработка

    npm install
    npm test                    # тесты сервера, админки и сайта, без базы
    npm run dev:server          # сервер, порт 3004
    npm run dev:admin           # админка, http://127.0.0.1:3005
    npm run dev:web             # сайт, http://127.0.0.1:5177

Тесты на настоящем Postgres, порты и миграции описаны в docs/STRUCTURE.md. Код на TypeScript
(сервер NestJS, сайт React и Vite), админка на чистом Node без зависимостей, служба ML на Python.

## Рядом

Это часть моих проектов, которые можно ставить вместе, а можно по отдельности.

- [DV Auth](https://github.com/Godween69/DVAuth): маленький сервис второго фактора входа. С DV Cloud
  работает из коробки, но нужен только если вы хотите второй фактор.
- [DVChat](https://github.com/Godween69/DVChat): закрытый семейный мессенджер на Matrix с
  приложением для Android и веб-версией. Свой сервер и свои аккаунты.
- [DVMail](https://github.com/Godween69/DVMail): минималистичный веб-клиент для почтового
  сервера Stalwart.

## Безопасность

Нашли уязвимость: не открывайте для неё публичную задачу, а воспользуйтесь закрытым сообщением на
вкладке Security (подробнее в SECURITY.md). Секретов в репозитории нет, настройки лежат в
dvcloud.env, который в git не попадает.
