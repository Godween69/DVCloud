# DVCloud

Домашнее облако для семейных фото и видео на вашем сервере. У каждого человека своё пространство, вход выдаёт администратор. Нужны фото и ничего лишнего.

**Статус: ранняя разработка.** Рабочей версии пока нет, в репозитории только документация. Не храните в проекте единственные копии своих фото, пока он не вышел из ранней стадии.

## Что будет уметь

- Отдельное пространство для каждого человека. Регистрации нет: людей заводит администратор.
- Веб-галерея: лента по дате съёмки, превью, просмотр оригиналов, корзина.
- Приложение для Android: автоматическая выгрузка фото и видео, по желанию только по Wi-Fi.
- Локальная админка: люди, квоты, состояние, импорт целой папки с компьютера или флешки.
- Оригиналы лежат на диске обычными файлами в понятных папках. Если приложение сломается, фото останутся целы и откроются без него.

Чего нарочно не будет: распознавания лиц и умного поиска, соцсети, публичных галерей, внешних сервисов и счётчиков.

## Как это будет устроено

    браузер или приложение  ->  HTTPS-прокси  ->  сервер (NestJS и сайт React)  ->  Postgres
                                                              |
                                                     файлы на диске
    локальная админка  ->  сервер (внутренний адрес, наружу не публикуется)

Подробно: docs/DESIGN.md.

## Устройство репозитория (план)

- apps/server: сервер на NestJS.
- apps/web: сайт на React и Vite.
- apps/admin: локальная админка.
- apps/android: приложение на Flutter.
- docs: документация. tools: служебные скрипты.
