# Поиск по смыслу

Поиск фото и видео словами: «собака на пляже», «скриншот переписки», «закат». Работает по-русски. Файлы никуда не
отправляются: нейросеть работает в вашем облаке.

## Как это устроено

Отдельный маленький сервис (apps/ml, Python, onnxruntime) превращает картинку и текст в векторы: наборы чисел, у которых
близкий смысл даёт близкие значения. Модель одна и та же для картинок и текста, поэтому текст можно сравнивать с картинкой.

Что происходит:

- Сервер берёт миниатюру файла (для видео кадр-постер) и отправляет её сервису. Вектор сохраняется в таблице embeddings
  (один вектор на физический файл, даже если он лежит у нескольких людей).
- При поиске сервис превращает запрос в вектор, сервер сравнивает его со всеми векторами человека (перебор в памяти,
  десятки миллисекунд на двадцать тысяч файлов) и отдаёт лучшие совпадения.
- Ищется только по своей библиотеке, без корзины. Чужие файлы и общие альбомы в выдачу не попадают.

Модель: многоязычная CLIP (текстовая часть XLM-RoBERTa base, картиночная ViT-B/32), лицензия MIT. Файлы модели лежат
на диске в каталоге с именем модели, например xlm-roberta-base-vit-b-32. Имя каталога записывается рядом с каждым вектором:
при смене модели старые векторы не смешиваются с новыми и считаются заново.

## Включение

1. Запустить сервис ML (контейнер dvcloud-ml, см. docker-compose.example.yml) и положить файлы модели
   (visual/model.onnx, textual/model.onnx, textual/tokenizer.json) в каталог, смонтированный в /models.
2. Задать серверу DVCLOUD_ML_URL, например http://ml:8090.
3. В админке на вкладке «Медиа» включить «Поиск по смыслу». Векторы считаются в фоне, по одному файлу, только когда нет
   загрузок. Ход виден там же. На строку поиска на сайте это влияет сразу: кнопка появляется, пока поиск включён.

По умолчанию поиск выключен: он нагружает процессор (на четырёх слабых ядрах это несколько часов на двадцать тысяч файлов,
один раз) и занимает память.

## Память и процессор

В памяти одновременно только одна половина модели: картиночная при индексации, текстовая при поиске. Через две минуты
простоя (DVML_IDLE_SEC) память возвращается системе. Потоков onnxruntime по умолчанию два (DVML_THREADS). Контейнеру стоит
задать ограничение памяти около 2,4 ГБ и ограничение процессора в два ядра.

## Сеть и безопасность

Сервис ML не нужен снаружи и не должен выходить в интернет. Разместите его в закрытой сети Docker (internal: true), в
которую входят только он и сервер DV Cloud. Запросов журнала у сервиса нет: запросы людей в нём не сохраняются.

## Программный интерфейс

Для сайта (нужен вход):

- GET /api/search/status отдаёт enabled, available, total, indexed: включён ли поиск, отвечает ли служба, сколько файлов
  человека в поиске и сколько уже готово.
- GET /api/search?q=текст&limit=120 отдаёт files (от лучшего совпадения, в каждом есть score) и indexed, total. Запрос от 1
  до 200 символов, limit от 1 до 300. Когда поиск выключен или служба недоступна, ответ 503 с понятным текстом.

Порог выдачи: остаются файлы не слабее заданного процента от лучшего совпадения (настройка «Строгость выдачи», от 50 до 95,
по умолчанию 80) и не слабее мягкого нижнего предела сходства (переменная DVCLOUD_SEARCH_MIN, по умолчанию 0.1).

Внутренний порт (для админки): GET /internal/media отдаёт блок search (готово, неудачно, в очереди, размер векторов,
состояние службы); POST /internal/media/clear с what=index (стереть все векторы) или what=index-failed (повторить неудачные).

## Служба ML

- GET /health: model, ready (файлы модели на месте), loaded (что сейчас в памяти).
- POST /embed/image: тело это картинка; ответ: model, dim, vector (base64 от float32, нормирован).
- POST /embed/text: тело {"text": "..."}; тот же ответ.
- Проверка настоящей модели: docker exec ИМЯ python -I app.py --selftest (файлы на месте, длины векторов, «кошка» рядом с
  «cat», расход памяти).

## Тесты

Сервис ML: python3 -I -m unittest discover -s apps/ml/tests (на крошечной подставной модели, нужны onnx, onnxruntime,
numpy, pillow, tokenizers). Сервер: apps/server/test/search.integration.ts с подставной службой, где смысл это цвет.
