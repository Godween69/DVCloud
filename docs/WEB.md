# Веб-интерфейс

React 19, Vite, Tailwind CSS 3, Framer Motion, lucide-react. Тот же набор, что на сайте-визитке
автора: тёмная тема по умолчанию (переключается, выбор хранится в localStorage),
фиолетовый акцент.

## Запуск для разработки

    npm run dev:server     # сервер, порт 3004
    npm run dev:web        # сайт, http://127.0.0.1:5177 (запросы /api уходят на сервер)

## Что умеет

- Вход по логину и паролю, выход. Если включён второй фактор: второй шаг с QR-кодом и числом
  для подтверждения в DVChat либо с полем для кода (docs/TWOFACTOR.md).
- Страница «Безопасность» (значок щита в шапке): привязка DVChat, коды из приложения,
  запасные коды.
- Библиотека по месяцам, плитки подгружаются по мере прокрутки.
- Просмотр: клавиши Esc, стрелки, свайп на телефоне, скачивание, видео со своим плеером.
- Загрузка: одна кнопка «Добавить» с выбором «Файлы» или «Папку» (папка только на компьютере) или перетаскивание файлов и папок в
  окно; три файла одновременно, у каждого свой прогресс, общий счётчик «Загружено N из M» и
  объём. Файл, который уже есть в облаке, не передаётся, а сразу добавляется («место не заняло»).
  Большие файлы (от 32 МБ) идут частями и докачиваются после обрыва. Перед большой пачкой
  показывается, влезет ли она в квоту, с вариантами «загрузить, сколько влезет» и «попросить
  больше места». Ожидающие можно отменить, неудавшиеся повторить. Подробно docs/FILES.md.
- Альбомы: одно фото может лежать в нескольких альбомах. Альбомом можно поделиться с другими
  людьми облака («Поделиться»): они видят его в своём списке с пометкой «Поделился: имя»,
  могут смотреть, скачивать и «Сохранить себе» (копии не занимают места на диске), но не менять
  его. Из чужого альбома можно «Убрать из списка». docs/ALBUMS.md.
- Корзина (раньше «Скрытые»): файлы с миниатюрами, «Восстановить», «Удалить навсегда», «Восстановить все»,
  «Очистить корзину» с подтверждением. Из просмотра и из режима выбора доступно «В корзину»,
  сразу после него появляется «Восстановить». Файлы в корзине ещё занимают место в квоте.
- Место: полоса занятого места в шапке (корзина тоже считается); цифры краснеют от 85 %,
  линия становится красной от 90 %.

## Что пока не сделано

- Превью. Сетка пока грузит оригиналы (лениво), поэтому на больших фото и на медленном
  канале она тяжёлая. Для видео показывается значок. Серверные превью и дата из EXIF
  следующий этап.
- HEIC в большинстве браузеров не открывается, но сервер делает для него миниатюру и превью (0.10.0), поэтому в сетке и просмотре он виден. Скачивание отдаёт оригинал.

## Тесты

    npm test --workspace @dvcloud/web

Проверяются логика очереди загрузок, группировка по месяцам и форматирование. Интерфейс
проверялся вручную в настоящем браузере на настоящем сервере.

## Вкладки, скриншоты, видео (0.3.0)

Вкладки: Библиотека (фото и видео без скриншотов), Фото (картинки без скриншотов), Видео, Скриншоты, Альбомы, Похожие, Корзина.
Фото, Видео и Скриншоты не пересекаются; выбор и «В корзину» работают на каждой так же, как в Библиотеке. Просмотр открывает облегчённое превью
(размер задаётся в админке), скачивание отдаёт оригинал. Видео проигрывается из уменьшенной копии, если она готова
и включена в админке, иначе из оригинала. У видео в плитке виден кадр с отметкой воспроизведения.

## Поиск по смыслу (0.5.0)

Когда администратор включил поиск, в верхней панели появляется кнопка с лупой. Она открывает страницу с одной строкой:
«собака на пляже», Enter или «Найти». Результаты идут от лучшего совпадения, а не по датам, их можно открыть в просмотре
(листаются стрелками) и убрать в корзину. Под строкой видно, сколько файлов поиск уже знает, если часть ещё
обрабатывается. Пока ничего не искали, показаны примеры запросов. Кнопки нет, пока поиск выключен. Подробно: SEARCH.md.

## Виды ленты (0.10.0)

Переключатель над лентой: «Умная плитка» (по умолчанию), «По месяцам», «Сплошная лента».
- Умная плитка: сетка одинаковых клеток, снимок занимает одну или несколько клеток по своей форме. Вертикальный кадр
  встаёт столбиком на две клетки в высоту, горизонтальный занимает две в ширину, каждый девятый (кроме узких вертикальных)
  растягивается на 2x2. Пустоты закрывает плотная укладка. Месяцы идут блоками с заголовками. Решение зависит только от формы
  снимка и его номера, поэтому при подгрузке снимков в конец ничего не прыгает (apps/web/src/lib/smart.ts).
- Переход по полосе времени срабатывает сразу: лента очищается, показывается заглушка, а нужный месяц подгружается в фоне.
- Верхняя и нижняя панели плотные, значки из lucide-react крупнее, активный раздел выделен ровной «таблеткой».

## Плавность и оформление (0.11.0)

- Плитки: мягкие скруглённые края, тонкая рамка и лёгкая тень (как у кругов в «Людях»); увеличение при наведении идёт на
  своём слое, без рывков.
- Верхняя и нижняя панели без размытия фона (оно перерисовывалось при каждой прокрутке); переключение экранов только проявление.
- Панель выбора внизу в цвет темы (светлая или тёмная), плавно выезжает и уходит.
- «Умная плитка»: вертикальные снимки не образуют стену одинаковых столбиков, чередуются столбик, крупный квадрат и малый.

## Видео-рамка и ручной вид (0.11.0)

Видео в сетке рисуется как кадр киноплёнки: тёмные боковые полосы с перфорацией и крупный значок «играть» (компонент `FilmFrame` в Gallery.tsx).
Панель выбора и просмотрщик имеют кнопки «В скриншоты» / «Это фото» (только для картинок), вкладки сразу убирают переехавший снимок.
