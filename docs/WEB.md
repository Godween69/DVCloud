# Веб-интерфейс

React 19, Vite, Tailwind CSS 3, Framer Motion, lucide-react. Тот же набор, что на лендинге
dvbstudio.ru: тёмная тема по умолчанию (переключается, выбор хранится в localStorage),
фиолетовый акцент.

## Запуск для разработки

    npm run dev:server     # сервер, порт 3004
    npm run dev:web        # сайт, http://127.0.0.1:5177 (запросы /api уходят на сервер)

## Что умеет

- Вход по логину и паролю, выход. Если включён второй фактор: второй шаг с QR-кодом и числом
  для подтверждения в DVChat либо с полем для кода (docs/TWOFACTOR.md).
- Страница «Безопасность» (значок щита в шапке): привязка DVChat, коды из приложения,
  запасные коды.
- Библиотека по месяцам, плитки подгружаются по мере прокрутки.
- Просмотр: клавиши Esc, стрелки, свайп на телефоне, скачивание, видео со своим плеером.
- Загрузка: кнопка «Добавить», кнопка «Загрузить папку» или перетаскивание файлов и папок в
  окно; три файла одновременно, у каждого свой прогресс, общий счётчик «Загружено N из M» и
  объём. Файл, который уже есть в облаке, не передаётся, а сразу добавляется («место не заняло»).
  Большие файлы (от 32 МБ) идут частями и докачиваются после обрыва. Перед большой пачкой
  показывается, влезет ли она в квоту, с вариантами «загрузить, сколько влезет» и «попросить
  больше места». Ожидающие можно отменить, неудавшиеся повторить. Подробно docs/FILES.md.
- Альбомы: одно фото может лежать в нескольких альбомах. Альбомом можно поделиться с другими
  людьми облака («Поделиться»): они видят его в своём списке с пометкой «Поделился: имя»,
  могут смотреть, скачивать и «Сохранить себе» (копии не занимают места на диске), но не менять
  его. Из чужого альбома можно «Убрать из списка». docs/ALBUMS.md.
- Скрытые (бывшая корзина): файлы с миниатюрами, «Вернуть», «Убрать насовсем», «Вернуть все»,
  «Убрать все насовсем» с подтверждением. Из просмотра и из режима выбора доступно «Скрыть»,
  сразу после него появляется «Вернуть». Скрытые файлы ещё занимают место в квоте.
- Место: полоса занятого места в шапке (скрытые тоже считаются); цифры краснеют от 85 %,
  линия становится красной от 90 %.

## Что пока не сделано

- Превью. Сетка пока грузит оригиналы (лениво), поэтому на больших фото и на медленном
  канале она тяжёлая. Для видео показывается значок. Серверные превью и дата из EXIF
  следующий этап.
- HEIC в большинстве браузеров не открывается: в просмотрщике предлагается скачать файл.

## Тесты

    npm test --workspace @dvcloud/web

Проверяются логика очереди загрузок, группировка по месяцам и форматирование. Интерфейс
проверялся вручную в настоящем браузере на настоящем сервере.

## Вкладки, скриншоты, видео (0.3.0)

Вкладки: Библиотека, Альбомы, Похожие, Скриншоты, Скрытые. «Библиотека» не показывает скриншоты, они
собраны на отдельной вкладке (выбор и скрытие работают так же). Просмотр открывает облегчённое превью
(до 2000 px), скачивание отдаёт оригинал. У видео в плитке виден кадр с отметкой воспроизведения.
