# Лицензия проекта

DV Cloud распространяется под **GNU Affero General Public License, версия 3** (AGPL-3.0).
Полный текст лежит в файле LICENSE в корне репозитория. В файлах package.json указан
идентификатор AGPL-3.0-only.

## Что это значит простыми словами

- Код открыт: его можно читать, запускать, менять, брать для своих целей.
- Если кто-то изменит код и выпустит свою версию, он обязан открыть исходники этой версии
  под той же лицензией (это свойство копилефта: «лево авторского права»).
- Отличие AGPL от обычной GPL: запуск изменённой версии как сетевого сервиса для других людей
  тоже считается распространением. Тот, кто поднимет изменённое облако для чужих людей,
  обязан дать им исходный код. Для сервера, работающего через сеть, это главная защита.
- Для личного и семейного использования автором никаких обязательств не возникает: автор
  может работать с собственным кодом как угодно.

## Права на код

Авторские права на код принадлежат автору проекта. Пока в проекте нет чужого кода,
лицензию можно изменить или дать тот же код другим людям на других условиях. Принимать
чужие правки в репозиторий стоит, только если автор правки согласен на условия проекта.

## Чужие библиотеки

Зависимости проверяет `npm run licenses` (файл tools/check-licenses.mjs). Правила:

- разрешены MIT, BSD, Apache-2.0, MPL-2.0;
- ISC, 0BSD и подобные свободные лицензии разрешены и видны в отчёте;
- копилефт, совместимый с AGPL-3.0 (LGPL-3.0, GPL-3.0, AGPL-3.0), разрешён и показывается
  отдельным списком; сейчас так лицензирована графическая библиотека libvips внутри sharp;
- GPL-2.0-only, LGPL-2.1-only, несвободные лицензии и пакеты без лицензии не допускаются.

Каждая новая зависимость проходит эту проверку до того, как попадёт в репозиторий.

## Поиск по смыслу: библиотеки Python и модель (0.5.0)

Служба ML (apps/ml) работает отдельным контейнером и не входит в сервер. Её зависимости зафиксированы в Dockerfile:
onnxruntime (MIT), numpy (BSD-3-Clause), Pillow (HPND, свободная лицензия в духе MIT), tokenizers (Apache-2.0).
Все подходят под правила выше. Модель многоязычной CLIP (OpenCLIP, веса laion5b s13b b90k) распространяется
под лицензией MIT; в репозиторий она не входит и скачивается отдельно по желанию владельца облака.
Перед сменой модели стоит проверить её лицензию: у некоторых моделей (например, у части многоязычных вариантов)
она запрещает коммерческое использование.
